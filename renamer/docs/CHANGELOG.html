v0.2.0 — 2026-10-08

เพิ่ม (Added)

ฟีเจอร์รายละเอียด
📂 Native folder pickerปุ่มเลือกโฟลเดอร์จริงผ่าน tauri-plugin-dialog แทนการพิมพ์ path
📋 Import List จากไฟล์เลือก CSV/TXT → สร้างกฎ Import List อัตโนมัติ รองรับแบบคู่ชื่อ old,new และเรียงลำดับ
⏳ Progress bar real-timeRust ส่ง event rename-progress ทุก 50 รายการขึ้นแถบสถานะ
📝 Log รายวันcore/logger.rs — ไฟล์ logs/renamer-YYYY-MM-DD.log, level ควบคุมด้วย RENAMER_LOG=debug, ใช้ร่วม GUI/CLI, ครอบสแกน/พรีวิว/rename/undo/rollback
IPC ใหม่parse_import_list, log_file_path
Frontend regression testsทดสอบการซิงก์กฎและตัวเลือกผ่าน IPC ก่อนพรีวิว และหยุดเมื่อ IPC ล้มเหลว
Tauri capabilitiesแก้ IPC โดน deny ตอน runtime
เอกสาร + AGENT.mddocs/ ครบ Markdown + HTML + แผนภาพ SVG + index

แก้ (Fixed)

ปัญหาผล
cargo run เปิด CLI แล้วออกด้วย exit code 2 แทน GUIตั้ง GUI เป็น binary หลักและแยก CLI เป็น renamer-cli
เปิด GUI dev ด้วย cargo run แล้ว WebView แสดง localhost:5173 refusedใช้ npm run tauri dev เพื่อเริ่ม Vite ก่อนเปิด GUI
Rust compiler warnings จาก imports/variables/functions ที่ไม่ได้ใช้เก็บ warnings ที่พบจาก build ให้หมด
GUI ไม่ได้ลงทะเบียน IPC สำหรับอัปเดตกฎและตัวเลือก และพรีวิวใช้ค่าเก่าลงทะเบียนคำสั่งและซิงก์ค่าก่อนพรีวิว; เปลี่ยนตัวเลือกแล้วพรีวิวอัปเดต
Virtual table ไม่จัดตำแหน่งแถวตาม scroll และชื่อไฟล์ถูกแทรกเป็น HTML โดยไม่ escapeจัดตำแหน่งแถวและ escape ชื่อก่อน render diff
Regex compile ซ้ำทุกไฟล์ → เพิ่ม RegexCacheพรีวิว 10k เร็วขึ้น 54× (3,270 ms → 60.6 ms)
สลับชื่อไฟล์ A↔B ล้มเหลว (เช็คปลายทางบัง + lookup temp ไม่เจอ)swap ทำงานถูกต้อง มี test ครอบ
Numbering แทรกเลขหลังนามสกุลในโหมด Fullแทรกก่อนนามสกุลเสมอ
UI ส่ง camelCase แต่ serde ต้องการ snake_caseกฎทั้งหมด round-trip ได้

v0.1.0 — 2026-10-08

เปิดตัวครั้งแรก

  • Core engine (Rust): สแกนขนาน (jwalk), กฎ 14 ประเภท grapheme-aware, validator, executor chain/cycle, journal write-ahead + Undo ข้าม restart
  • GUI (Tauri 2 + Svelte 5): live preview virtual list, ไฮไลต์ diff, แก้ชื่อมือได้, preset, i18n ไทย/อังกฤษ, ธีม Dark/Light, คีย์ลัด
  • CLI: preview / undo / presets, dry-run ค่าเริ่มต้น, exit codes
  • Tests: เกณฑ์ยอมรับ 1–7 ครบ + benchmark (~60 ms สำหรับ 10k ไฟล์)
  • Build: installer NSIS (1.37 MB) + MSI (1.98 MB)
