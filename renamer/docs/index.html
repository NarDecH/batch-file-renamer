📁 Batch File Renamer

เปลี่ยนชื่อไฟล์และโฟลเดอร์หลักแสนพร้อมกัน — ปลอดภัยต่อข้อมูลเป็นอันดับหนึ่ง

Rust + Tauri 2 ติดตั้งแค่ 1.4 MB Preview 10k ไฟล์ ≈ 60 ms Windows (หลัก)

หน้าแรก คู่มือ (README) วิจัยและเหตุผล (Research) สิ่งที่เปลี่ยน (Changelog) README.md

✦ทำไมต้องใช้ตัวนี้

🛡️ ปลอดภัยก่อนอะไรทั้งปวง

ตรวจปลายทางบนดิสก์ทุกไฟล์ทุกครั้ง, journal write-ahead, ยกเลิกแล้ว rollback คืนทั้งชุด, Undo ได้แม้ปิดโปรแกรมไปแล้ว

⚡ เร็ว 54 เท่าจากการวัดจริง

Pipeline 10,000 ไฟล์ × 5 กฎ ใช้เพียง ~60 ms (จากเดิม 3.27 s) — ตาราง 100k แถวเลื่อนลื่นด้วย virtual list

🔤 เข้าใจภาษาไทยจริง

ตัด/แทรกข้อความแบบ grapheme — สระ วรรณยุกต์ อีโมจิ ไม่หลุดลอย พร้อมรองรับชื่อสงวนของ Windows ครบ

🧩 กฎ 14 ประเภท + Preset

Replace, Regex, EXIF วันที่ถ่าย, แท็กเพลง, Numbering, Import CSV… บันทึกชุดกฎใช้ซ้ำได้ทั้ง GUI และ CLI

👁️ เห็นก่อนแตะ

พรีวิวสดทุกครั้งที่แก้กฎ ไฮไลต์ส่วนที่เปลี่ยน แก้ชื่อทับด้วยมือได้ ยืนยันอีกครั้งก่อน rename จริง

🖥️ GUI + CLI ในเดียว

engine ชุดเดียวกัน — ใช้เมาส์ใน GUI หรือเขียนสคริปต์ผ่าน CLI ก็ได้ผลเหมือนกันเป๊ะ

🗺️สถาปัตยกรรม

🚀เริ่มใช้ใน 30 วินาที

# dev
cd renamer && npm install
npm run build && cd src-tauri && cargo run

# แจกจ่าย (ได้ NSIS + MSI installer)
npm run tauri build

# CLI
renamer --dry-run preview -f "D:\Photos" -r --include "*.jpg" -p photos
renamer --apply preview -f "D:\Photos" -r --include "*.jpg" -p photos
renamer undo
