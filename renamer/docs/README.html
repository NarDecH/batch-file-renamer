Batch File Renamer v0.2.0

หน้าแรก README Research Changelog

01ภาพรวม

โปรแกรมเปลี่ยนชื่อไฟล์และโฟลเดอร์จำนวนมากพร้อมกัน — ปลอดภัยต่อข้อมูล, เร็วระดับไฟล์หลักแสน, เห็นผลลัพธ์ก่อนเปลี่ยนจริงเสมอ

Tech StackRust (core) · Tauri 2 · Svelte 5
แพลตฟอร์มWindows (หลัก) · โค้ดเขียน cross-platform
ขนาดตัวติดตั้ง~1.4 MB (NSIS) / ~2 MB (MSI)
Performanceพรีวิว 10,000 ไฟล์ × 5 กฎ ≈ 60 ms

02ฟีเจอร์

นำเข้า

native folder picker, recursive + กำหนดความลึก, กรอง wildcard/regex/ขนาด/วันที่, natural sort

กฎ 14 ประเภท

Replace, Regex, Insert, Remove, Case, Numbering, Extension, Date/Time, Metadata, Template, Clean up, Swap, Import List (CSV/TXT), Hash/UUID

Live Preview

ตาราง virtualized, ไฮไลต์ส่วนที่เปลี่ยน, สีสถานะ, แก้ชื่อมือได้ (ดับเบิลคลิก)

ปลอดภัย

ชื่อซ้ำ/ชื่อสงวน/อักขระต้องห้าม, conflict 3 โหมด, journal write-ahead, rollback อัตโนมัติ

Undo + Log

ย้อนหลังข้าม restart + log รายวัน (RENAMER_LOG=debug)

Preset / i18n / CLI

บันทึกชุดกฎ, ไทย/อังกฤษ, Dark/Light, คีย์ลัด, CLI dry-run ค่าเริ่มต้น

03ติดตั้งและรัน

cd renamer
npm install
npm run build
cd src-tauri && cargo run      # โหมด dev

# Build แจกจ่าย → src-tauri/target/release/bundle/
npm run tauri build

04ใช้งาน CLI

renamer --dry-run preview -f "D:\Photos" -r --include "*.jpg" -p photos
renamer --apply     preview -f "D:\Music"  -r -p music
renamer undo
renamer presets

Exit codes: 0 สำเร็จ · 1 ไม่มีอะไรให้ undo · 2 สแกน/พรีวิวล้มเหลว · 3 rename บางรายการล้มเหลว

05ตัวอย่างการใช้งานจริง 5 กรณี

#สถานการณ์วิธีทำผลลัพธ์
1ตั้งชื่อรูปตามวันที่ถ่ายpreset photos (EXIF date + numbering)IMG_20240315_143022.JPG → 2024-03-15_001.JPG
2จัดชื่อเพลงpreset music (Template + Clean up)Artist - Title.mp3
3ชื่อ URL-friendlyClean up (strip accents, space→-) + Case lowerCafé Ñandú Ep 1.mp4 → cafe-nandu-ep-1.mp4
4สลับชื่อไฟล์สองไฟล์แก้ชื่อใหม่ด้วยมือในตารางengine จัด cycle ด้วย temp name อัตโนมัติ
5เลขรัน natural sortNumbering (pad 3)ep1, ep2, ep10 → ep001, ep002, ep010

06เกณฑ์ยอมรับ (automated tests)

#เกณฑ์ผล
1Pipeline ครบ → Trip_2024-03-15_001.jpg✅
2สลับ a.txt ↔ b.txt เนื้อหาถูกต้อง✅
3photo.JPG → photo.jpg ไม่ถูกมองว่าซ้ำ✅
4ชื่อซ้ำแจ้งเตือน + auto-suffix (1)✅
5Natural sort + เลขรัน 001/002/003✅
6Undo หลังปิดโปรแกรม✅
7ไทย/อีโมจิ ลบ 1 ตัวแรกไม่มีสระลอย✅
8Preview 10k × 5 กฎ ≤ 200 ms✅ ~60 ms

07Logging สำหรับดีบัก

ไฟล์ log รายวันที่ %APPDATA%/batch-renamer/logs/renamer-YYYY-MM-DD.log

RENAMER_LOG=debug renamer --dry-run preview -f "D:\Photos"
