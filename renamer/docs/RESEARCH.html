3ความปลอดภัย — การออกแบบให้ "ไฟล์ไม่หาย"

rename เขียนทับได้

std::fs::rename ทับปลายทางได้ทั้ง Windows/Unix → เช็คดิสก์ก่อนทุกครั้ง, ยกเว้นเฉพาะ chain + case-only

Cycle A↔B

rename ตรง ๆ พังเพราะชื่อยังถูกใช้ → ใช้ temp name __rntmp__<uuid> + เก็บ map temp→final ตั้งแต่รอบแรก

Journal write-ahead

เขียน JSON ก่อน rename แรก + อัปเดตทุกรายการ → แครชกลางทาง Undo ได้จากไฟล์

ยกเลิกกลางทาง

rollback ทุก rename ที่ทำไปแล้ว ไม่ทิ้งไฟล์ชื่อ temp ค้าง

Grapheme safety (ภาษาไทย) — พบจาก test จริง

"น้ำตก" = น + ้ + ำ + ต + ก แต่ grapheme cluster คือ ["น้ำ","ต","ก"] — ใช้ char ตัด 1 ตัวจะได้ "้ำตก" (สระลอย) ใช้ unicode-segmentation ตัด 1 cluster ได้ "ตก" ถูกต้อง — ครอบด้วย automated test (criterion 7)
