📁 Batch File Renamer

เปลี่ยนชื่อไฟล์และโฟลเดอร์หลักแสนพร้อมกัน — ปลอดภัยต่อข้อมูลเป็นอันดับหนึ่ง

Rust + Tauri 2 ติดตั้งแค่ 1.4 MB Preview 10k ไฟล์ ≈ 60 ms Auto-update ในตัว Windows (หลัก)

⬇️ ดาวน์โหลดเวอร์ชันล่าสุด (Windows) ดู release ทั้งหมด

หน้าแรก คู่มือ (README) วิจัยและเหตุผล (Research) สิ่งที่เปลี่ยน (Changelog) บันทึกชุด 0.12.x (Timeline) README.md

✦ทำไมต้องใช้ตัวนี้

🛡️ ปลอดภัยก่อนอะไรทั้งปวง

ตรวจปลายทางบนดิสก์ทุกไฟล์ทุกครั้ง, journal write-ahead, ยกเลิกแล้ว rollback คืนทั้งชุด, Undo ได้แม้ปิดโปรแกรมไปแล้ว

⚡ เร็ว 54 เท่าจากการวัดจริง

Pipeline 10,000 ไฟล์ × 5 กฎ ใช้เพียง ~60 ms (จากเดิม 3.27 s) — ตาราง 100k แถวเลื่อนลื่นด้วย virtual list

🔤 เข้าใจภาษาไทยจริง

ตัด/แทรกข้อความแบบ grapheme — สระ วรรณยุกต์ อีโมจิ ไม่หลุดลอย พร้อมรองรับชื่อสงวนของ Windows ครบ

🧩 กฎ 13 ประเภท + Preset

Replace, Regex, EXIF วันที่ถ่าย, แท็กเพลง, Renumber (บวก/ลบเลขในชื่อแบบสัมพันธ์ หรือใส่เลขลำดับใหม่ — กฎเดียวจบ), Import CSV… บันทึกชุดกฎใช้ซ้ำได้ทั้ง GUI และ CLI

🔢 Renumber — เลขแบบสัมพันธ์

บวก/ลบเลขที่ฝังในชื่อไฟล์ทีละไฟล์ IMG_0100 +1 → IMG_0101, IMG_0999 +1 → IMG_1000 · เลือกเลื่อนเลขชุดแรก/สุดท้าย/ทุกชุด · เตือนเมื่อชื่อใหม่จะทับชื่อไฟล์อื่นในชุด (shift-chain)

🗂️ สแกนหลายโฟลเดอร์ + ตัวกรอง

เลือกโฟลเดอร์เดิม ๆ หลายที่เข้าชุดเดียวกันได้ + กรองไฟล์ตามขนาด (min/max MB) และวันที่แก้ไข (จาก/ถึง) — ทั้ง CLI และ GUI ใช้ engine เดียวกัน

👁️ เห็นก่อนแตะ

พรีวิวสดทุกครั้งที่แก้กฎ ไฮไลต์ส่วนที่เปลี่ยน แก้ชื่อทับด้วยมือได้ ยืนยันอีกครั้งก่อน rename จริง

🖥️ GUI + CLI ในเดียว

engine ชุดเดียวกัน — ใช้เมาส์ใน GUI หรือเขียนสคริปต์ผ่าน CLI ก็ได้ผลเหมือนกันเป๊ะ (CLI รับหลาย path ได้แล้ว)

🔄 อัปเดตอัตโนมัติ

เปิดโปรแกรมครั้งถัดไปจะเช็คเวอร์ชันใหม่จาก GitHub Releases เอง — กดปุ่มเดียว ติดตั้ง+รีสตาร์ท ทุกอัปเดตตรวจลายเซ็นก่อนติดตั้ง

cargo run --bin renamer-cli -- undo
